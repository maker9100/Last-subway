# Last Train

실제 한국 시간으로 운행하는 3D 1인칭 소셜 철도 웹게임이다. Node.js 20, Express, 순수 WebSocket, Vite, Three.js로 구성했다. 이미지·모델·사운드 파일이나 CDN 없이 Canvas 텍스처, 기본 지오메트리, WebAudio를 사용한다.

## 1. 로컬 실행

Node.js 20.19 이상인 20 버전과 npm을 설치하고, 이 README와 package.json이 있는 폴더에서 실행한다.

```bash
npm ci
npm run dev
```

브라우저에서 http://localhost:3000 을 연다. 개발 모드에서도 Express가 Vite 미들웨어와 `/ws`를 같은 포트에서 처리한다. 별도 프록시나 서버 두 개가 필요하지 않다.

배포 모드 확인:

```bash
npm test
npm run build
npm start
```

`http://localhost:3000/healthz`는 `ok`, `/`는 게임 화면을 반환한다. `index.html`을 파일로 직접 열면 동작하지 않는다. WebGL 2를 지원하는 브라우저와 하드웨어 가속이 필요하다. 외부 배포에서는 HTTPS를 사용한다.

## 2. 조작

| 조작 | 기능 |
| --- | --- |
| WASD / Shift | 걷기 / 빠르게 걷기 |
| 마우스 / 화면 드래그 | 시점 회전 |
| E | 가까이 조준한 대상 상호작용 / 활동 마치기 |
| F | 3.5m 안 플레이어에게 인사 |
| 1 / 2 / 3 / 4 / 5 | 손 흔들기 / 고개 숙임 / 박수 / 춤 / 앉기 |
| Enter / Esc | 채팅 열기·전송 / 채팅 또는 마우스 잠금 해제 |
| M / 노선도 버튼 | 현재 열차 위치와 역별 도착 안내 |
| 왼쪽 가상 스틱 | 모바일 이동 |

접속 후 화면 중앙의 계속하기 버튼을 누르면 마우스가 잠긴다. 대합실은 역사 뒤쪽 열린 출입구로 들어간다. 앉기·독서 등 활동을 마치려면 E를 다시 누른다. 도감은 해당 브라우저 localStorage에 저장된다. 저장이 차단되어도 플레이는 계속된다.

티켓 부스에서 목적지를 고르고 플랫폼 문 앞에서 정차 중에 E를 누른다. 객실 앞문에서 정차 중에 E로 내릴 수 있다. 목적지를 지나쳐도 자동으로 내리지 않는다. 해변역과 심해역의 잠수함은 티켓 없이 20초 뒤 이동한다. 심해 채집은 잠수복과 수중 구역 진입이 필요하다.

## 3. GitHub 저장소 만들기와 푸시

1. GitHub에 로그인하고 오른쪽 위 `+` → `New repository`를 누른다.
2. 이름을 `last-train`으로 정하고 공개 여부를 선택한다.
3. README, .gitignore, license 자동 추가를 선택하지 않고 `Create repository`를 누른다.
4. 생성 화면의 HTTPS 저장소 주소를 복사한다.
5. 이 README가 있는 폴더에서 아래 명령을 실행한다. 마지막 입력 요청에는 방금 복사한 실제 주소를 붙여 넣는다.

```bash
git init
git add .
git commit -m "Implement Last Train"
git branch -M main
read -r -p "GitHub 저장소 HTTPS 주소: " LAST_TRAIN_GIT_URL
git remote add origin "$LAST_TRAIN_GIT_URL"
git push -u origin main
```

Windows PowerShell에서는 `read` 대신 `$LAST_TRAIN_GIT_URL = Read-Host 'GitHub 저장소 HTTPS 주소'`를 사용한다. Git 인증은 브라우저 또는 GitHub의 인증 안내를 따른다. `package-lock.json`과 `.npmrc`를 반드시 함께 커밋한다. node_modules와 dist는 업로드하지 않는다.

## 4. Render 연결

1. Render 대시보드에서 `New +` → `Web Service`를 누른다.
2. GitHub 계정을 연결하고 위 저장소를 선택한다.
3. 런타임 `Node`, 브랜치 `main`을 선택한다.
4. 저장소 최상위가 package.json 폴더라면 `Root Directory`를 비운다. 상위 폴더에 last-train 디렉터리를 통째로 넣었다면 `last-train`을 입력한다.
5. Build Command는 `npm ci && npm run build`, Start Command는 `npm start`로 설정한다.
6. Environment에 `NODE_VERSION=20`, `NODE_ENV=production`을 설정한다.
7. Health Check Path에 `/healthz`를 입력한다.
8. 플랜을 선택하고 `Create Web Service`를 누른다.
9. 배포 로그에 빌드 완료와 `Last Train: http://0.0.0.0:`가 표시되고 서비스 상태가 정상인지 확인한다.
10. Render가 발급한 HTTPS 주소를 연다.

`render.yaml`을 이용하려면 `New +` → `Blueprint`에서 저장소를 선택해 같은 설정을 적용할 수 있다. `.npmrc`의 `include=dev` 덕분에 NODE_ENV가 production이어도 빌드에 필요한 정확한 Vite 버전이 설치된다.

## 5. 환경변수와 운영 범위

| 이름 | 값 / 의미 |
| --- | --- |
| PORT | Render가 주입한다. 로컬 기본값은 3000이다. |
| NODE_VERSION | Render 설정값 20 |
| NODE_ENV | production |

API 키나 데이터베이스는 필요하지 않다. 한 Node 프로세스에서 룸과 재접속 세션을 관리하므로 Render 인스턴스 수는 1개로 유지한다. 수평 확장에는 별도의 공유 상태 계층이 필요하다. 한 IP에서 최대 8개, 전체 512개의 연결을 허용한다. 학교처럼 공인 IP를 공유하는 환경이라면 `shared/constants.js`의 `LIMITS.ipConnections`를 조정한다.

세션은 접속 종료 뒤 15분 동안 서버 메모리에 남는다. 같은 탭을 새로고침하면 sessionStorage의 임의 토큰으로 원래 위치에 복귀한다. 서버 재시작·재배포·슬립으로 세션이 없어지면 중앙역에서 다시 시작한다. 열차 시간표는 현재 시각으로 재구성되며, 수집 도감은 해당 브라우저에 남는다. 재접속 시 이전 활동은 종료하며 잠수함의 도착 시각은 유지한다.

Render 무료 서비스는 유휴 상태에서 슬립할 수 있어 첫 접속이나 재접속이 늦어질 수 있다. 계속 켜 둬야 한다면 유료 인스턴스를 선택하거나 Render 이용 정책이 허용하는 범위에서 외부 상태 확인 서비스가 `/healthz`를 조회하게 구성한다. 외부 핑이 상시 가동이나 무료 사용량을 보장하지는 않는다.

## 6. 시간표 해석

중앙 → 초원 → 설원 → 해변 → 심해 → 정글 → 산맥 → 사막 → 중앙 순서다. 구간은 450초이며 처음 60초는 문이 열리고, 나머지 390초 동안 달린다. 열차 ID는 `floor((UTC 밀리초 + 9시간) / 300000)`이다. KST 자정에 기준 운행이 시작되며 해당 열차의 문은 00:00:00부터 00:00:59.999까지 열린다. 실제 움직임은 00:01:00부터다. 명세의 구간 시작 정차 규칙을 적용한 결과다.

예를 들어 00:00 기준 열차는 00:07:30 초원, 00:15:00 설원, 00:22:30 해변, 00:30:00 심해, 00:37:30 정글, 00:45:00 산맥, 00:52:30 사막, 01:00:00 중앙에 도착한다. 각 역 도착 간격은 5분이다. 매 구간의 도착과 출발 시각을 서버가 다시 검증한다.

동시에 12편성만 존재하도록 중앙역 복귀 시 동일 편성의 다음 운행 ID는 이전 ID+12가 된다. 계속 타고 있는 승객도 이 운행 ID의 객실로 동기적으로 옮긴다. 자정에 ID를 초기화하지 않는다.

서버 시간표에는 디버그 쿼리가 영향을 주지 않는다. 다음 주소로 시각·계절·기념일의 클라이언트 연출만 확인할 수 있다.

```text
http://localhost:3000/?season=winter&event=halloween&time=2026-10-31T12:00:00%2B09:00
```

season은 spring/summer/autumn/winter, event는 newyear/seollal/fullmoon/children/chuseok/halloween/christmas/none을 지원한다. 서버의 티켓과 추석 송편 제공 여부는 실제 날짜를 따른다.

## 7. 달력 정확도

KST 날짜와 계절은 UTC 밀리초에 9시간을 더하고 UTC getter로 구한다. 음력은 ICU의 `en-u-ca-chinese`와 `Asia/Seoul`을 사용한다. 2026년 설날 2월 17일, 정월대보름 3월 3일, 추석 9월 25일은 한국천문연구원 월력요항으로 검증한 폴백을 둔다. 2027~2040년의 검증하지 않은 양력 날짜는 하드코딩하지 않았다. 해당 연도에 Intl 중국력이 없으면 음력 기념일을 생략하고 계절과 양력 기념일은 계속 적용한다. 런타임이 제공하는 중국력과 한국 음력의 모든 연도별 차이를 보증하지 않는다.

## 8. 배포 후 확인

- `/healthz`가 200과 `ok`를 반환한다.
- 화면이 뜨고 닉네임 검증 후 중앙역에 입장한다.
- 개발자 도구 Network에서 `/ws`가 101로 연결된다.
- 다른 탭에 다른 닉네임을 입력하면 상대 아바타와 채팅이 보인다.
- 부스 발권 후 정차 시간에 탑승하고, 다음 역에서 내릴 수 있다.
- 창을 새로고침하면 같은 열차 또는 역에 복귀한다.
- 해변·심해 잠수함과 잠수복 채집이 동작한다.
- Esc, 채팅, 모달 사용 중 캐릭터가 의도치 않게 움직이지 않는다.
- 휴대전화에서 가상 스틱, 터치 회전, E 버튼을 확인한다.

## 9. 문제 해결

| 증상 | 확인 / 해결 |
| --- | --- |
| npm ci 실패 | package.json과 제공된 package-lock.json을 함께 사용한다. Node 20.19 이상인 20 버전을 사용한다. |
| vite를 찾을 수 없음 | `.npmrc`가 누락되지 않았는지 확인한다. `include=dev`가 필요하다. |
| 빈 화면 / WebGL 오류 | 브라우저 하드웨어 가속과 WebGL 2 지원을 확인한다. Console의 첫 오류를 확인하고 강력 새로고침한다. |
| 배포 화면이 503 | Build Command가 실행됐는지와 Root Directory를 확인한다. dist가 package.json과 같은 프로젝트 아래 생성되어야 한다. |
| WebSocket 연결 실패 | HTTPS 페이지의 wss 연결과 `/ws` 경로를 확인한다. HTTP 페이지에 HTTPS 전용 중간 프록시를 섞지 않는다. 무료 서비스의 초기 기동을 기다린다. |
| 시간이 맞지 않음 | HUD의 온라인 표시를 확인한다. 탭 복귀 시 재동기화한다. URL의 time 쿼리는 조명 연출만 바꾼다. 서버 호스트의 UTC 시계는 정확해야 한다. |
| E키가 반응하지 않음 | 마우스 잠금 여부, 대상까지 2.5m 거리와 조준점을 확인한다. 활동 중이면 E로 먼저 마친다. |
| 열차가 있는데 탑승 불가 | 문이 열린 60초와 유효한 서버 발권 티켓이 필요하다. 열차가 출발하는 순간 서버가 닫힘으로 판정할 수 있다. |
| 닉네임 중복 / 동시 접속 제한 | 중복 이름에는 숫자가 붙는다. 같은 IP 연결 제한은 constants.js에서 조절한다. |
| 새로고침 뒤 중앙역으로 복귀 | 서버가 재시작됐거나 15분 유예가 지났거나 sessionStorage가 차단된 경우다. |
| 수집 기록이 없음 | 다른 브라우저·기기·도메인에는 공유되지 않는다. 저장 차단이나 사이트 데이터 삭제 여부를 확인한다. |

## 10. 검증과 그래픽 단순화

`npm test`는 시간표, 달력, 서버 통합, 절차 모델 생성, Three.js 리소스 해제를 검증한다. 상세 근거는 `VERIFICATION.md`에 있다. 자동 테스트는 실제 GPU 성능, 모바일 터치나 Pointer Lock 체험을 대신하지 않는다.

텍스처와 인물은 낮은 폴리곤·픽셀 스타일이며 그림자는 사용하지 않는다. 파도·불·앰비언트는 간단한 기하 변화와 합성음이다. TV는 절차 생성 자막 프로그램이며, 독서는 세 장짜리 창작 여행 메모와 책 소품으로 표현한다. 망원경은 시야각 확대, 그네·해먹·썰매는 짧은 자세와 카메라 연출이다. 포인트 파티클로 낙엽·벚꽃·눈·박쥐·기포·불꽃을 표현한다. 눈사람·발자국 등 임시 월드 효과는 현재 접속자에게 전달되고 제한 시간 후 사라진다. 좌석 독점·물리 시뮬레이션·영구 건축 상태는 구현 범위에 포함하지 않는다.
